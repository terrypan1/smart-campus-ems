# EMS 操作手冊

示範大學主校區能源管理系統（Demo，校名為虛構）。網址：部署環境 http://localhost:3020

> Demo 的電表資料全部是模擬產生（51 顆電表、13 個月歷史＋即時模擬），數字不代表任何學校的實際用電。

## 1. 登入與角色

| 角色 | 可以做的事 |
|---|---|
| 管理者（admin） | 全部頁面；修改契約容量、電價、時段方案、離峰日、排碳係數、電表、使用者；確認告警 |
| 檢視者（viewer） | 看所有資料頁面；確認告警；看不到「系統設定」 |

- 右上角：時鐘、**告警鈴鐺**（未確認數）、淺色／深色切換、使用者選單（**變更密碼**、登出）
- 忘記密碼：請管理者在「系統設定 → 使用者」重設臨時密碼，登入後自己變更

## 2. 各頁面怎麼看

### 2.1 首頁 → 用電總覽（登入後的首頁）

由上到下回答三個問題：

1. **現在有沒有超標**：目前這個 15 分鐘區塊的平均淨需量 ÷ 經常契約容量。燈號見 §3。
2. **今天有沒有超標**：今天最高需量、發生時間、距離契約多少 kW；今天超約的區塊數、警戒與卸載事件數。
3. **整體資訊＋去年同期**：今日用電、本月用電、本月最高需量、本月電費（試算）、本月碳排、太陽能、系統狀態。
   - ▲ 紅色＝比去年同期**增加**、▼ 綠色＝**減少**（節能的意思：用電、需量、電費、碳排增加是壞事）
   - 滑過去可以看比較的期間：今日＝去年同一個星期幾（往前 364 天）的同一時間；本月＝去年同月 1 號到同一天的同一時間

每張卡片點下去會到對應的詳細頁。

### 2.2 即時監控 → 電表清單

每 10 秒更新：每顆電表的即時 kW、電壓、電流、功率因數、累積電度、通訊狀態（超過 3 分鐘沒讀值＝斷線）；上方是各大樓即時用電。

### 2.3 用電分析

- **用電趨勢**：每日（近 31 天）或每月（近 13 個月）用電，依台電時段分顏色（尖峰／半尖峰／週六半尖峰／離峰）。
  - 灰色「**未分時段**」：電表斷線期間的用電。斷線前後的累積電度相減知道總共用了多少，但不知道是哪幾個小時用的，所以不分時段、不補值。
  - 「**不可計算**」的小時：整點前後 20 分鐘內找不到讀值（小時邊界規則）。
  - 下方「每小時明細」可以選電表與日期看每個小時，「斷線範例」按鈕直接跳到 Demo 安排的三個斷線事件。
- **用電結構**：依空間類型、用途看占比，大樓排名（依用途堆疊）。點大樓可以看該棟各電表。

### 2.4 需量管理 → 需量監控

- 目前需量、本月各時段最高需量、契約容量與警戒門檻（管理者可在這裡直接修改）
- 15 分鐘需量曲線：紅線＝經常契約、虛線＝警戒門檻；超約的區段標紅；底色＝時段
- 近 13 個月各時段最高需量、需量事件（即時偵測＋歷史補記）

**需量**：台電電表以 15 分鐘平均計算需量。本系統用「每個整 15 分鐘區塊的用電 × 4」。太陽能視為自發自用，需量用「用電－太陽能」（淨需量）。

### 2.5 電費

- **電費估算**：選月份看各時段度數、基本電費、功率因數調整、超約附加費、流動電費、應繳總額。每一列都寫了算式與條文編號。
  - 為什麼是「**試算**」：計費週期用日曆月（台電實際依抄表日）、未分時段度數依比例分攤、幾項條文由本系統解讀（頁面下方列出）。
  - 營業稅：台電電價**已內含** 5% 營業稅，畫面上的營業稅是從總額拆出來給你看，不是另外加。
  - 本月還沒結束時，流動電費只算到今天，基本電費仍以整月計。
- **電價設定**：現行費率、時段、離峰日、計算規則與出處。管理者可以改費率（改過的會標色，滑過去看公告值）、還原台電公告值、切換時段方案、新增農曆離峰日。

### 2.6 ESG → 碳排放

範疇二（外購電力）排放＝淨用電 × 經濟部能源署電力排碳係數；太陽能減碳＝發電 × 係數。跨年度逐月套各自年度的係數；還沒公告的年度暫用最近一個已公告年度（標「暫用」）。右上角可以匯出 Excel（每月明細，給 ESG 報告用）。

> 只計算範疇二、地點基準；不含範疇一、三；不等於正式溫室氣體盤查。

### 2.7 告警 → 告警事件

| 類型 | 什麼時候出現 | 什麼時候結束 |
|---|---|---|
| 需量警戒 | 目前需量達警示門檻（含模擬卸載） | 需量回到門檻下、且那個 15 分鐘區塊結束 |
| 超約 | 目前需量超過該時段契約容量 | 同上 |
| 電表斷線 | 某電表超過 3 分鐘沒有讀值 | 恢復讀值 |
| Modbus 連線中斷 | 採集連不上電表的 Modbus 位址 | 恢復連線 |
| 電度倒退 | 累積電度變小（換表或資料異常） | 不會自動結束，請人工確認 |
| 資料缺漏 | 某電表某天可計算的小時 < 95% | 不會自動結束，請人工確認 |

- 同一件事只會有一筆（有開始、有結束），不會每分鐘洗版
- 「未確認」看要處理的、「進行中」看還沒恢復的；勾選後「確認選取」可以批次確認
- 標「歷史」的是重算歷史資料時補記的（例如 Demo 的三個斷線事件），已由系統確認，不計入鈴鐺

## 3. 燈號意義

| 燈號 | 條件（以經常契約容量的百分比） | 意思 |
|---|---|---|
| 🟢 正常 | < 警示門檻（預設 70%） | 不用處理 |
| 🟡 已達警戒 | ≥ 警示門檻 | 留意，可以準備卸載 |
| 🟠 卸載中（模擬） | ≥ 關空調門檻（預設 85%，再上去是關進排風 90%、關照明 95%） | 系統記錄「模擬卸載」事件，**不會真的關設備** |
| 🔴 超過契約容量 | ≥ 該時段契約容量 | 會被台電收超約附加費（契約 10% 內 2 倍、超過 3 倍基本電費） |

## 4. 系統設定（管理者）

| 頁面 | 內容 |
|---|---|
| 契約與係數 | 契約容量與警戒門檻、電力排碳係數（能源署公告新年度後新增）、全部重算彙總、重新補記歷史告警 |
| 電表設定 | 名稱、用途、啟用、Modbus 連線（**接真實電表時只要改這裡**）；「測試連線」立即讀一次；不能刪除，只能停用 |
| 使用者 | 新增、編輯角色與啟用、重設密碼；最後一個啟用中的管理者不能停用或降級 |
| 稽核紀錄 | 所有設定修改：時間、帳號、項目、修改前後 |

**什麼時候要「全部重算」**：改了時段方案（三段式／二段式）或離峰日之後。新資料會立即套用新設定，歷史的用電趨勢、需量、電費要重算才會更新（約 10–30 秒）。改電價、契約、排碳係數不用重算（查詢時才計算）。

## 5. 常見問題

| 問題 | 說明 |
|---|---|
| 今天的需量曲線最右邊是空的 | 曲線畫到「最近一個已結束的 15 分鐘區塊」；進行中的區塊看目前需量 |
| 今日用電顯示「—」 | 今天 00:00 前後找不到讀值（例如系統當時沒在跑），無法用頭尾相減，不顯示偏低的數字 |
| 某些區塊標「部分資料」 | 那個區塊有電表缺讀值，需量會偏低 |
| 國定假日也有很高的需量 | Demo 模擬器不知道國定假日，照平日產生用電；電價面已正確算成全日離峰 |
| 電費估算出現「二段式不提供試算」 | 時段方案切成二段式；費率表只有三段式（大學適用），切回三段式即可 |
