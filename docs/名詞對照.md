# 名詞對照（畫面用字一律照這份）

畫面、文件、回報都用**台電帳單與能源管理系統（EMS）業界的正式用語**，不自創說法。不好懂的詞第一次出現時，在旁邊加一句說明。

## 1. 需量與契約（單位 kW）

| 用語 | 意思 | 畫面上的說明（第一次出現時） |
|---|---|---|
| **需量** | 每 **15 分鐘**的平均用電，單位 kW（瓩）。電表每 15 分鐘記一次，一小時 4 個、一個月約 2,880 個 | 需量＝每 15 分鐘的平均用電（kW） |
| **目前需量** | 目前這個 15 分鐘需量區間，從區間開始到現在的平均用電（kW）。常見電力監控系統畫面用「目前需量」，業界也稱「即時需量」 | 本需量區間開始到現在的平均用電 |
| **目前時段** | 現在屬於哪個時間電價時段（電力監控系統常見用語） | — |
| **需量曲線** | 一天裡每 15 分鐘的需量連成的線 | — |
| **最高需量** | 計費期間（一個月）裡最大的那一個需量；台電用它判斷超約 | — |
| **契約容量** | 跟台電約定的最高需量上限（kW）。Demo 校區只訂「經常契約」1,900 kW | — |
| **經常契約／半尖峰契約／週六半尖峰契約／離峰契約** | 台電電價表的契約種類，各時段可用的容量 | — |
| **超約** | 最高需量超過契約容量 | — |
| **超約附加費** | 超約時，超出部分加收的基本電費（契約 10% 以內 2 倍、超過 3 倍） | — |
| **需量監控** | 監看需量是否逼近契約容量 | — |
| **需量控制** | 需量逼近上限時卸載設備，壓低最高需量（本系統只模擬記錄，不實際控制） | — |
| **預警值** | 需量達契約容量的某個百分比時發出預警（本系統預設 70%） | — |
| **卸載**／**復歸** | 暫時關閉可中斷的設備（空調、進排風、照明）／恢復 | 卸載（模擬）＝只記錄，不會真的關設備 |
| **需量警報** | 需量跨過預警值、卸載值或超約時記下的事件 | — |
| **瞬時功率** | 電表這一刻量到的功率（kW），不是 15 分鐘平均 | — |
| **負載** | 用電設備同時在用的功率（kW），例：全校負載、大樓即時負載 | — |

## 2. 用電量與電費（單位 度＝kWh）

| 用語 | 意思 |
|---|---|
| **用電量** | 用了多少電，單位**度**；**1 度＝1 kWh**（1 kW 用 1 小時）。每小時、每日、每月加總 |
| **時間電價時段** | 尖峰、半尖峰、週六半尖峰、離峰（台電正式名稱） |
| **夏月／非夏月** | 高壓用戶夏月 5/16–10/15 |
| **基本電費** | 依契約容量計收（元／kW／月） |
| **流動電費** | 依各時段用電量（度）計收（元／度） |
| **功率因數調整** | 月平均功率因數高於／低於 80% 時扣減／加收基本電費 |
| **離峰日** | 國定假日等全日按離峰計價的日子 |

## 3. 太陽能與碳排

| 用語 | 意思 |
|---|---|
| **自發自用** | 太陽能發的電學校自己用掉，不賣給台電 |
| **外購電力** | 向台電買的電＝用電量－太陽能發電量 |
| **電力排碳係數** | 經濟部能源署每年公告，每度電的排碳量（公斤 CO2e／度） |
| **碳排放量** | 外購電力 × 電力排碳係數（公噸 CO2e） |
| **範疇二** | 溫室氣體盤查中「外購電力」造成的間接排放 |
| **減碳量** | 太陽能自發自用少買的電 × 電力排碳係數 |

## 4. 不要用的說法

| 不要寫 | 改成 |
|---|---|
| 用電功率、現在的用電、今天的最高用電、即時需量 | 需量、目前需量、今日最高需量 |
| 這一刻的用電 | 瞬時功率 |
| 即時用電（kW 時） | 即時負載 |
| 每 15 分鐘的用電功率 | 需量曲線 |
| 警示 | 預警 |
| 超過契約容量（當狀態名稱） | 超約 |
| 向台電買的電 | 外購電力 |
| 淨需量 | 需量（已扣除太陽能發電） |
