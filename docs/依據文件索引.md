## 3. 本系統的解讀（條文沒寫清楚，畫面標「試算」或「估算」）

| 項目 | 解讀 | 理由 | 出處 |
|---|---|---|---|
| 小時邊界「不允許用 09:10:01」 | 有更接近的 09:00:01 時必須取最接近的 | 抄表規則的例子 | 02 §2.1 |
| 斷線期間的用電 | 總量已知、時段未知 → 「未分時段」，不補值 | 使用者 2026-10-05 確認 C 方案 | 02 §2.3 |
| 超約的 10% 基準 | 各時段用自己的累計契約容量 | 條文只寫「契約容量」 | 03 §3.4 |
| 超約計費單價 | 各時段用該時段的契約電價 | 同上 | 03 §3.4 |
| 功率因數調整的基數 | 套用在契約內的基本電費；超約部分不扣減 | 七(二)「超約部分不給予功率因數扣減」 | 03 §3.4 |
| 月平均功率因數 | 當月用電電表讀值 Σkw ÷ √(Σkw²＋Σkvar²) | 讀值等間隔，正比於 kWh、kvarh | 03 §5 |
| 5 月、10 月跨夏月 | 基本電費依日數比例拆分 | 條文未寫 | 03 §3.4 |
| 計費週期 | 日曆月（台電實際依抄表日） | Demo 簡化 | 03 §3.4 |
| 15 分鐘需量算法 | 整 15 分鐘區塊用電 × 4，頭尾 ±5 分鐘取最接近 | 台電電表是 15 分鐘平均，條文未定義 | 03 §3.4 |
| 未分時段度數的電費 | 依當天已量測的時段比例分攤（當天沒有已量測時用全月比例） | 總量已知、時段未知 | 03 §3.4 |
| 太陽能 | 自發自用：帳單度數、需量、碳排都用「用電－發電」 | 模擬校區太陽能遠小於用電 | 03 §3.4、05 §2.2 |
| 國定假日 | 國曆固定日期每年套用；農曆日期依年度新增（系統設定） | Demo 簡化 | 03 §3.4、06 §3.1 |
| 114 年度排碳係數口徑 | 用公用售電業 0.467（不用產業 0.466、民生住宅 0.471） | 跟 111～113 同一口徑；學校不是住宅 | 05 §1 回報 |
| 碳排範圍 | 只算範疇二、地點基準；不含範疇一、三，不等於正式盤查 | 只量得到外購電力 | 05 §2 |
| 同期比較 | 今日＝往前 364 天（同星期幾）同一時間；本月＝去年同月 1 號到同一天同一時間 | 平日對平日、到同一時間點 | 04 §3 |
| 二段式時的電費 | 不提供試算 | 費率表只有三段式（大學適用） | 06 回報 |
